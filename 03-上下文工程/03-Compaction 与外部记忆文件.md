历史太长了要压缩，这一步几乎每个长会话 agent 都会做。而它同时也是最容易把关键约束悄悄弄丢的一步。

## 一句话

压缩是**有损**的，所以真正的设计问题不是「怎么压得更好」，而是**「哪些东西绝对不许被压掉」**——尤其是安全约束。

## 原理

### 什么时候压

触发条件通常是这几个之一：

- 历史 token 数超过预算上限，见 [[02-Context engineering：上下文即预算]]
- 轮数超过阈值
- 距离上次压缩超过 N 轮

**别等窗口满了才压。** 那时候要么来不及，要么压得太狠。留出余量，在预算的七八成就开始。

### 怎么压

| 做法 | 保真度 | 成本 |
| --- | --- | --- |
| 滑动窗口（丢最旧的） | 最低——直接丢 | 零 |
| 摘要压缩（旧的几轮总结成一段） | 中 | 一次模型调用 |
| 分层摘要（摘要再摘要） | 中低，会累积漂移 | 多次 |
| **外置**（挪到文件/向量库） | **最高——不丢** | 存储 + 检索 |

**最后一行是最该优先的。** 压缩会丢信息，外置不会——它只是把东西从窗口挪到别处，需要时再取回来，见 [[01-短期与长期记忆分层]]。

一个务实的组合：**能外置的外置，外置不了的才压缩，压缩时保护关键片段。**

### 外部记忆文件

对 agent 类系统，最简单有效的外置形式是一个**它自己能读写的文件**：

```text
## 任务目标
把这批发票的 8 个字段抽出来，输出 JSON

## 已完成
- inv-001 ~ inv-042 已处理，结果写入 output.jsonl
- 发现扫描歪的要先做旋转校正

## 待办
- inv-043 起

## 踩到的坑
- 手写金额识别率低，已改为标记 needs_review
```

好处很实在：**它是持久的、可检查的、人也能读的**。窗口被压缩之后，agent 从这个文件重新读回状态，比从一段模型生成的摘要里恢复可靠得多。

而且它天然支持断点续跑——进程挂了，状态还在文件里，见 [[05-断点续跑]]。

### 那个必须知道的失效模式

> [!danger] 压缩会悄悄抹掉安全约束
> 有研究把这个现象叫 **governance decay**：在长时程 agent 里，上下文压缩会**静默地擦除安全约束**。
>
> 机制很直接：安全规则通常写在早期的系统提示或早期轮次里，压缩时被当成「旧的、不重要的」摘掉了。而摘要模型不知道哪句是安全约束、哪句是闲聊。
>
> 后果是**没有任何报错**——agent 继续跑，只是不再受那些约束了。跑了几十轮之后它可能已经忘了「不许执行删除操作」这条。

防法：

- **把安全约束和关键指令钉死在系统提示里，永远不参与压缩**
- 压缩后做一次**约束校验**：确认关键规则还在窗口里
- 关键约束不只写在提示词里，同时在**工具层做硬性检查**——提示词会被压掉，代码不会，见 [[06-四层参数校验]]
- 定期把约束**重新注入**，而不是指望它一直留着

最后一条最省事：每 N 轮把安全约束重新贴一遍到窗口末尾。代价是几百 token，换的是约束不会失效。

### 压缩本身要能被验证

压缩是一次模型调用，它也会出错——漏掉关键信息、篡改事实、把待办压没了。

所以要有验证：

- **关键槽位检查**：任务目标、当前进度、待办清单必须还在
- **可逆性**：原始历史别删，存到外部，出问题能回查
- **压缩前后各跑一次**关键判断，看结论一不一致

这也是 harness 思路的应用——给压缩这一步也配个验证器，见 [[01-Harness engineering]]。

### 怎么衡量做得好不好

**成功率随轮数的衰减曲线**，加压缩前后各画一条，见 [[06-上下文衰减与长轮次退化]]。

再加一条更狠的：**在第 30 轮问一个只有第 3 轮提到过的事实**，看还答不答得出来。这个测试能直接暴露压缩丢了什么。

## 动手做

- [ ] 给一个长会话 agent 加上摘要压缩，画压缩前后的衰减曲线
- [ ] 改成外置到文件，再画一条，对比三者
- [ ] 做「第 30 轮问第 3 轮的事」测试，看三种做法各答得出多少
- [ ] 在系统提示里放一条安全约束，跑 50 轮压缩，检查它还在不在——验证 governance decay
- [ ] 给压缩加一个关键槽位检查器，故意让它压掉待办清单，确认能被拦住
- [ ] 实现约束的定期重注入，算清楚它多花多少 token

## 算学会了

- [ ] 知道压缩是有损的，能外置就不压缩
- [ ] 安全约束钉死在系统提示里，且在工具层有硬性检查兜底
- [ ] 压缩后会校验关键槽位还在不在
- [ ] 有外部记忆文件，agent 能从它恢复状态
- [ ] 会用「后期问早期事实」测试压缩丢了什么

## 坑

**压掉了安全约束还不知道。** 最危险的一个，因为它完全静默。

**只靠提示词维持约束。** 提示词会被压缩，代码不会。关键约束必须有工具层兜底。

**等窗口满了才压。** 来不及，而且只能压得很狠。

**摘要再摘要。** 分层摘要会累积漂移，几轮之后内容已经和原文对不上了。

**删掉原始历史。** 压缩出问题时无从回查。存到外部，别删。
