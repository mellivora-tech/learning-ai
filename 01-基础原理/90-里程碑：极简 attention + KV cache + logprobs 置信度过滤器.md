## 交付物

三段自己写的代码，各自能通过一个客观校验：

1. **20 行以内的 causal attention**，和 `F.scaled_dot_product_attention(..., is_causal=True)` 数值对齐到 `atol=1e-5`
2. **带 KV cache 的逐 token 生成**，和不带 cache 的全量重算**逐 token 完全一致**
3. **基于 logprobs 的置信度过滤器**，能把「模型很笃定」和「模型在瞎猜」分开

外加一组实测数字（下面「结果与数据」那张表）。

现在跑会停在第 1 关。每关都有参照实现当裁判，不用自己判断对错：

| 关 | 要填 | 谁当裁判 |

三关都过之后，再补这几组实测：

1. **耗时比**——带 cache 和不带 cache 各生成 512 个 token，记录耗时。理论上差 $T$ 倍，实际会小一些，想清楚差在哪
2. **去掉 $\sqrt{d_k}$**——把 `dh` 扫到 32 / 512 / 2048，记录 softmax 权重的最大值和熵，看分布怎么塌成 one-hot
3. **置信度阈值**——拿一批真实输出，人工标出好坏，找出能把两者分开的阈值，记录在这个阈值下拦掉了多少、误伤了多少
