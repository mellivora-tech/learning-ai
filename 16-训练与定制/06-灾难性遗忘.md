微调之后目标任务的准确率从 72% 涨到 91%。三周后有人发现，它在另外五个功能上都退了。

## 一句话

在窄领域上激进微调会损害通用能力，而这**不会体现在你训练时看的那个指标上**——所以必须单独测，且要有明确的收手门槛。

## 原理

![[遗忘要靠对照才看得见.excalidraw.md|700]]

### 为什么会发生

微调是在原有权重上继续做梯度下降。新任务的梯度会把权重推离原来的位置，而原来那个位置编码着模型在**所有其他任务**上的能力。

数据越窄、训得越狠，推得越远。表现为：

| 退化形态 | 例子 |
| --- | --- |
| 通用知识变差 | 常识问答退步 |
| 指令遵循变差 | 不再听 system prompt |
| 格式泛化变差 | 只会输出训练时那种格式 |
| 多语言能力退化 | 只用中文数据训，英文能力掉 |
| 拒答能力消失 | 训练数据里全是「有问必答」 |

**最后两条最隐蔽**，因为它们在目标任务的 eval 上完全看不出来。

### LoRA 好一些但不免疫

LoRA 冻住原权重，只训新增的低秩参数，见 [[03-LoRA 与 QLoRA]]。所以它对遗忘的缓解确实更好——原权重物理上没被改。

**但不是免疫。** 适配器的输出会叠加到每一层上，激进训练一样会让整体行为偏离。有研究专门分析了低秩适配下遗忘的几何机制。

### 一个可操作的门槛

> [!tip] 通用基准掉超过 2–3 个点就该收手
> 这是个实践中被反复验证的经验值。掉超过这个幅度，说明训得太狠了。
>
> 三个调节旋钮，按优先级：
> 1. **降学习率**
> 2. **减训练轮数**——过拟合往往就是遗忘的开始
> 3. **用更小的 rank**

**关键是要真的去测。** 只看目标任务的 eval，这个门槛无从判断。

### 混入通用数据

最便宜有效的缓解手段：**训练集里混入 5–10% 的通用指令数据**。

成本几乎为零（公开数据集直接拿），效果明显——它给了梯度一个「别走太远」的约束。

比例不用精调，5% 和 10% 差别不大。**关键是有，而不是有多少。**

### 别只测「通用基准」

用 MMLU 之类的公开基准测通用能力是必要的，但不够。要补两类：

**一、你自己系统的其他功能。** 如果这个模型还服务别的路径，那些路径的 golden set 都要跑一遍，见 [[01-Golden set]]。

**二、行为层面的检查**：

- 还听 system prompt 吗
- 拒答能力还在吗——见 [[06-检索评估两段式]]
- 输出格式还能泛化吗（给一个训练时没见过的 schema）
- 多轮对话还正常吗

**这几项不在任何公开基准里，但用户会立刻感觉到。**

### 部署上的规避

有时候不必在训练上妥协，换个部署方式就行：

| 做法 | 说明 |
| --- | --- |
| **一个基座 + 多个适配器** | 每个任务一个 LoRA，运行时按需加载，互不干扰 |
| **专用模型只服务专用路径** | 微调后的模型只处理那个窄任务，别的走原模型 |
| **路由分流** | 按请求类型选模型，见 [[04-模型路由与级联]] |

**第一种最优雅**：适配器只有几十 MB，切换成本低，而且天然隔离了遗忘的影响范围。

### 多次微调会累积

在已经微调过的模型上再微调一次，遗忘会累加。所以：

- **每次都从原始基座开始训**，而不是在上一版微调结果上继续
- 需要多个能力的话，**把数据合并一次训完**，而不是分几次增量训

**「在上一版基础上再训一点」是最容易埋雷的做法**——每一次都只掉一点，几轮下来模型已经面目全非。

## 动手做

- [ ] 微调前记录通用基准的基线分数
- [ ] 微调后重测，确认掉幅在 2–3 个点以内
- [ ] 同时跑你系统其他功能的 golden set
- [ ] 检查四项行为：听不听 system prompt、会不会拒答、格式能不能泛化、多轮正不正常
- [ ] 混入 5–10% 通用数据重训一次，对比退化幅度
- [ ] 试一次「一个基座 + 多适配器」的部署方式
- [ ] 验证每次微调都是从原始基座开始，而不是叠加

## 算学会了

- [ ] 微调后一定测通用能力，有明确的收手门槛
- [ ] 训练集里混了通用数据
- [ ] 测的不只是公开基准，还有自己系统的其他功能和四项行为
- [ ] 知道 LoRA 缓解但不免疫遗忘
- [ ] 每次从原始基座开始训，不做增量叠加

## 坑

**只测目标任务。** 退化完全看不见，上线几周后才被发现。

**在上一版微调结果上继续训。** 遗忘会累积，几轮下来模型面目全非。

**不混通用数据。** 一个几乎免费的保护措施被跳过了。

**只测公开基准。** 拒答能力、格式泛化、多轮这几项不在里面，但用户会立刻感觉到。

**以为 LoRA 就不会遗忘。** 它缓解，不免疫。
