## 交付物

一份选型报告，加一个能复跑的评测脚本。报告里必须有：

- 硬约束清单，以及每条砍掉了哪些候选
- 短名单怎么来的（用了哪个榜、为什么是那个榜）
- 30–50 条**真实**样本的评测结果表：准确率、单次成本、P95 延迟、失败模式各一列
- 最终选择，以及「为什么不是更贵的那个」——这一句是整份报告的重点
- 存成版本化文件的样本集，直接作为 [[01-Golden set]] 的第一版

## 做法

1. 挑一个手头真实的任务，不要用玩具题目
2. 写硬约束：数据能不能出内网、许可证、上下文长度、延迟预算、自建还是 API
3. 用榜单收到 3–5 个候选，跨档位选（比如 7B / 32B / 闭源大模型各一个）
4. 从线上流量抽样并标注，含脏数据和边缘情况
5. 同一套提示词跑全部候选，注意每个模型用它自己的 chat template
6. 记四类数字，特别记下每个模型**错在哪类输入上**
7. 找出「最小够用」的那一档，算它和最贵那档的成本差

## 复盘

- 榜单排名和你的实测排序一致吗？不一致的地方说明了什么
