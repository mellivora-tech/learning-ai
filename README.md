# learning-ai

AI Engineer 的个人学习笔记，Obsidian vault。19 个主题目录，143 篇笔记。

入口是 **[00-总索引](00-总索引.md)**：里面有 0–10 阶段学习路线、目录边界规则、写作约定，以及全部笔记的索引。

**目录编号就是推进顺序**——从 01 往后走，前面的是后面的前提。

想直接看内容，从这三篇开始：

- [一个模型到底是什么](01-基础原理/00-一个模型到底是什么.md) —— 架构、权重、推理服务三者的区别，猜一个 token 的完整流程，推理引擎和训练引擎各管什么
- [Transformer 与 attention](01-基础原理/01-Transformer%20与%20attention.md) —— 从 RNN 的瓶颈讲到 attention 的机制、block 结构、KV cache 的由来
- [模型是怎么来的](02-读懂一个模型/00-模型是怎么来的.md) —— 预训练到对齐四步走，以及为什么微调灌不进事实

## 用 Obsidian 打开

clone 之后直接把目录作为 vault 打开。插件代码没有入库，Obsidian 会按 `.obsidian/community-plugins.json` 提示你安装：Dataview、Templater、Excalidraw、Tasks 等。总索引末尾的进度视图依赖 Dataview。
